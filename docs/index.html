Данные и приватность

Сайт статический. У нас нет форм, аналитики или cookies, которые ставит страница. GitHub обслуживает сайт и обрабатывает технические данные посетителей по своей политике.

Навык выполняет работу средствами Claude Code или Codex. Для локального экспорта он обрабатывает файлы в среде, где запущен, и не отправляет их на отдельный сервер рендера. При разрешённой установке FFmpeg менеджер пакетов обращается к своему репозиторию. Данные чата обрабатывает выбранное AI-приложение.
