Навык для Claude Code и Codex

ИИ-видеомонтажёрдля твоих исходников

Дай агенту запись и монтажное задание. Он подскажет, что оставить или переснять, предложит склейки с таймкодами и при наличии FFmpeg соберёт ролик.

Как установитьПример монтажа ↓
Запрос к ИИ

Сделай из интервью вертикальный ролик. Оставь паузу перед главной репликой.

Разбор съёмки

Проверь звук, кадр, свет и подачу. Узнай, что можно исправить монтажом и что лучше переснять.

Склейки и субтитры

Согласуй порядок реплик, перебивки и субтитры для коротких роликов, интервью, Reels и Shorts.

Локальный экспорт

Собери согласованную версию через FFmpeg в локальной сессии с доступом к исходникам.

Вымышленный диалог

Оставь паузу. Верни реплику.

Агент объясняет, почему оставил паузу, и точечно правит следующий вариант по твоим замечаниям.

Ты

Сделай из записи салона вертикальный ролик на 20 секунд. Вырежи паузы.

Video Editor AI

Паузу на 00:07 после «Я только чуть-чуть подровняю» я бы оставил. Она работает на шутку. Сокращу вступление и предложу превью с субтитрами.

Ты

Оставь паузу. Верни реплику с 00:12. Субтитры оставь на том же месте.

Video Editor AI

Верну реплику в новой версии, сохраню положение субтитров и проверю синхронизацию.

Установи Video Editor AI

Выбери способ установки. Для экспорта открой локальную сессию, которая видит твои клипы и имеет доступ к FFmpeg.

После установки открой новую сессию и выбери video-editor. В Claude Code нативный плагин добавляет команду /video-editor-ai:video-editor.

Через интерфейс
  1. Claude Code Desktop. Если в браузере плагинов есть добавление источника, укажи bearatol/video-editor-ai. Иначе добавь этот ключ в .claude/settings.json проекта через редактор, сохрани существующие настройки и заново открой доверенный локальный проект.
    {
  "extraKnownMarketplaces": {
    "video-editor-ai-plugins": {
      "source": {
        "source": "github",
        "repo": "bearatol/video-editor-ai",
        "ref": "v0.1.1"
      }
    }
  }
}

    Рядом с полем сообщения открой «+» → Add plugins или Plugins → Browse plugins. Выбери источник Video Editor AI, затем Video Editor AI → Install.

  2. Codex Desktop. Клонируй репозиторий через GitHub Desktop и открой эту папку как проект. После перезапуска приложения открой Plugins, выбери источник Video Editor AI и установи плагин для этого проекта. GitHub.
  3. Claude в браузере. Скачай ZIP навыка, затем открой Customize → Skills → Create skill → Upload a skill. Это загружает только навык. Доступ к локальным файлам и FFmpeg зависит от среды. Скачать ZIP навыка.
Запросом к агенту

Вставь в локальный Claude Code или Codex с доступом к проекту и инструментам:

Установи Video Editor AI из https://github.com/bearatol/video-editor-ai для текущего проекта. Открой официальную инструкцию проекта, выбери способ для этой среды и проверь, что появился навык video-editor. Если среда требует одобрения, запроси его. FFmpeg пока не устанавливай.
Через APM

Если APM уже установлен, выполни из папки проекта. APM подключит навык к обоим агентам и запишет версию в apm.lock.yaml.

apm install bearatol/video-editor-ai/plugins/video-editor-ai#v0.1.1 --target claude,codex
Через skills.sh

Если доступен Node.js 22.20+, установи навык из текущей папки проекта и выбери агента в мастере установки.

npx skills@1.9.0 add bearatol/video-editor-ai --skill video-editor
Карточка в skills.sh
Нативные команды

Claude Code

/plugin marketplace add bearatol/video-editor-ai

Codex CLI

codex plugin marketplace add bearatol/video-editor-ai --ref main
codex plugin add video-editor-ai@video-editor-ai-plugins

Данные и приватность

GitHub Pages обслуживает этот статический сайт. На странице нет форм и аналитики. Данные сессии обрабатывает выбранное приложение.

При локальном экспорте навык обрабатывает файлы в среде агента без отдельного сервиса рендера. Если попросишь установить FFmpeg, поддерживаемый менеджер пакетов обратится к своему репозиторию.
