Install Video Editor AI

Choose an installation method. For export, use a local session with access to your clips and FFmpeg.

After installation, open a new session and select video-editor. The native Claude Code plugin provides /video-editor-ai:video-editor.

In the app
  1. Claude Code Desktop. If the plugin browser lets you add a source, enter bearatol/video-editor-ai. Otherwise use a text editor to add this key to the project’s .claude/settings.json, preserve any existing settings, and reopen the trusted local project.
    {
  "extraKnownMarketplaces": {
    "video-editor-ai-plugins": {
      "source": {
        "source": "github",
        "repo": "bearatol/video-editor-ai",
        "ref": "v0.1.1"
      }
    }
  }
}

    Next to the prompt box, select “+” → Add plugins, or Plugins → Browse plugins. Select the Video Editor AI source, then Video Editor AI → Install.

  2. Codex Desktop. Clone the repository with GitHub Desktop and open that folder as a project. Restart the app, open Plugins, choose the Video Editor AI source, and install the plugin for the project. GitHub.
  3. Claude in your browser. Download the skill ZIP, then open Customize → Skills → Create skill → Upload a skill. This adds the standalone skill. Local files and FFmpeg depend on the environment. Download skill ZIP.
Ask your agent

Paste into a local Claude Code or Codex session with access to the project and tools:

Install Video Editor AI from https://github.com/bearatol/video-editor-ai for this project. Read the project’s official installation guide, use the method supported here, and verify that the video-editor skill is available. Ask me if the environment requires approval. Leave FFmpeg installation for a separate request.
With APM

With APM installed, run this from the project directory. APM installs the skill for both agents and records the version in apm.lock.yaml.

apm install bearatol/video-editor-ai/plugins/video-editor-ai#v0.1.1 --target claude,codex
With skills.sh

With Node.js 22.20 or later, run this from your project directory and choose an agent in the installer.

npx skills@1.9.0 add bearatol/video-editor-ai --skill video-editor

Data and privacy

GitHub Pages hosts this static site. The page has no forms or analytics. Your chosen app handles session data.

Local export processes files in your agent’s environment without a separate rendering service. If you ask to install FFmpeg, a supported package manager contacts its package repository.
