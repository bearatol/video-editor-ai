检查声音、构图、灯光和表达，判断哪些问题能靠剪辑解决，哪些镜头值得补拍。

本地导出

安装 Video Editor AI

选择适合你的安装方式。导出成片时，请使用能够访问素材和 FFmpeg 的本地会话。

安装后开启新会话并选择 video-editor。Claude Code 原生插件提供 /video-editor-ai:video-editor 命令。

在应用中安装
  1. Claude Code 桌面版：如果插件浏览器支持添加来源，输入 bearatol/video-editor-ai。也可以用文本编辑器将以下设置合并到项目的 .claude/settings.json，保留原有设置，然后重新打开受信任的本地项目。
    {
  "extraKnownMarketplaces": {
    "video-editor-ai-plugins": {
      "source": {
        "source": "github",
        "repo": "bearatol/video-editor-ai",
        "ref": "v0.1.1"
      }
    }
  }
}

    点击输入框旁的「+」，选择 Add plugins，或 Plugins → Browse plugins。选择 Video Editor AI 来源，再选择 Video Editor AI → Install。

  2. Codex 桌面版：使用 GitHub Desktop 克隆仓库，将该文件夹作为项目打开。重启应用，在 Plugins 中选择 Video Editor AI 来源，然后为该项目安装插件。 GitHub.
  3. Claude 网页版：下载技能 ZIP，打开 Customize → Skills → Create skill → Upload a skill 并上传。这只会添加独立技能。能否访问本地文件和 FFmpeg 取决于会话环境。 下载技能 ZIP.
让智能体安装

将这段话发给能访问项目和使用工具的本地 Claude Code 或 Codex 会话：

请为当前项目安装 https://github.com/bearatol/video-editor-ai 里的 Video Editor AI。先阅读项目的官方安装说明，再按当前环境支持的方式安装，并检查 video-editor 技能是否可用。如果环境需要批准，请先询问我。暂时不要安装 FFmpeg。
通过 APM 安装

已安装 APM 时，在项目目录运行以下命令。APM 会为两个智能体接入技能，并将版本记录在 apm.lock.yaml 中。

apm install bearatol/video-editor-ai/plugins/video-editor-ai#v0.1.1 --target claude,codex
通过 skills.sh 安装

使用 Node.js 22.20 或更高版本，在项目目录运行命令，然后在安装向导中选择智能体。

npx skills@1.9.0 add bearatol/video-editor-ai --skill video-editor

数据与隐私

这个静态网站由 GitHub Pages 托管，页面没有表单或分析脚本。会话数据由你选择的应用处理。

本地导出在智能体的运行环境中处理文件，无需单独的渲染服务。如果你要求安装 FFmpeg，受支持的包管理器会连接其软件仓库。
