# Video Editor AI

Review footage and choose what to keep, trim or reshoot. Build a cut plan with source in and out timecodes and caption cues. Refine the cut and export locally with installed FFmpeg and ffprobe when the host supports it. An explicit installation request is required before the skill installs FFmpeg through a supported, existing package manager. The skill works with supplied media in the host environment.

- Review an interview and list three changes with timecodes.
- Plan a 45-second vertical edit with captions.
- Export an approved cut locally and keep the source files intact.

For Claude Code 2.1.275 or later, run:

```text
/plugin install video-editor-ai --marketplace bearatol/video-editor-ai
```
